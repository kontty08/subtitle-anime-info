Privacy policy

Last updated: October 14, 2026. This application is for its owner’s personal use.

  • Access: YouTube account/channel information and analytics, using only youtube.readonly and yt-analytics.readonly permissions. Monetary reporting, publishing, edits, deletion, and report-job creation are excluded.
  • Purpose: Collect channel and video performance data and generate private reports and suggestions for later videos.
  • Storage: Credentials are kept outside source control, including encrypted GitHub Actions Secrets. Reports are stored in a private GitHub repository. Current history files are retained for approximately one year; earlier versions may remain in private Git history until the owner removes them.
  • Processing: Google provides API data, GitHub hosts scheduled execution and private storage, and OpenAI processes credential-free analytics for analysis. OpenAI processing is subject to the owner’s account and data controls. Credential values are not supplied in AI prompts or included in reports.
  • Sharing: No analytics or credentials are published on this website. The application does not sell this data or use it for advertising.
  • Control: The owner can stop workflows, remove stored reports and Secrets, and revoke Google access in Google Account security settings. Revocation stops future API access but does not itself delete previously saved reports.

Google data use is subject to the Google API Services User Data Policy, including Limited Use requirements.

The owner’s support contact is provided on the Google OAuth consent screen. This application does not offer public sign-up.
